# 🎓 Student Management System

A simple, user-friendly, and database-driven **Student Management System** developed using Python. This project helps educational institutions manage student records efficiently through a graphical user interface (GUI).

## 📌 Project Overview

The Student Management System is a Python-based desktop application designed to store, manage, update, search, and delete student information.

It provides an easy way to maintain student records digitally instead of using traditional manual registers.

## ✨ Features

- ➕ Add New Student
- 📋 View All Students
- 🔍 Search Student Records
- ✏️ Update Student Details
- 🗑️ Delete Student Records
- 💾 Automatic Database Storage
- 🖥️ User-Friendly Graphical Interface
- 🔒 Data Management Using SQLite

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main Programming Language |
| Tkinter | Graphical User Interface |
| SQLite | Database Management |
| VS Code | Code Editor |
